Tutorial Guide

1
Download file zip dan extract folder b7_inspeksi ke D atau E (jangan di C), kemudian buka folder tersebut
2
klik kanan database lalu buka menggunakan notepad, lalu copy semua isi nya dan exit
3
buka Postgree, kemudian pilih Database, dan klik kanan pada database -> Create -> Database
4
masukan nama database = db_inspeksi , kemudian klik save
5
klik kanan pada db_inspeksi, kemudian pilih query tool
6
lalu masukan database.sql tadi yang di copy dari notepad, dan klik button seperti yang ditandai warna merah sampai muncul messages seperti yang tertera dibawah, kemudian exit postgree
7
lalu balik ke folder awal, dan klik kanan pada file installer.exe dan pilih opsi Run as administrator, jika muncul pesan Do you want to apply maka klik Yes
8
kemudian muncul CMD dan ketik R lalu enter, tunggu sampai proses instalasi selesai dan muncul informasi ip address dan muncul notifikasi Seluruh Layanan Berhasil di install dan di jalankan, kemudian copy ip adrress dan port nya dan jangan close terminal CMD nya
9
lalu akses alamat tersebut di browser dengan login user : admin pass : admin123
